# 우봉고 · 솔로 타임어택

보드게임 우봉고(Ubongo)를 혼자 시간 재며 즐기는 웹 게임입니다. 개인 학습용 팬메이드입니다. (원작: Grzegorz Rejchtman · KOSMOS)

## 규칙

- 아래에 나온 조각을 **모두** 사용해 판의 모래색 칸을 빈틈없이 채우면 한 문제 성공입니다.
- 조각은 돌리거나 뒤집어서 놓을 수 있습니다.

## 모드

- **제한시간**: 3·5·10분 동안 최대한 많이 풀기
- **스피드런**: 5·10·20문제를 최대한 빨리 풀기
- **난이도**: 쉬움(조각 3개) / 어려움(조각 4개) / 섞기(3~4개)
- 모든 문제는 조각을 실제로 이어 붙여 만들기 때문에 항상 답이 있습니다.

## 조작

- **드래그**: 조각 옮기기
- **탭** / R키: 90° 회전
- **흔들기**: 조각을 든 채 좌우로 빠르게 한 번 흔들면 좌우 뒤집기, 위아래로 흔들면 상하 뒤집기
- **뒤집기 버튼** / 우클릭 / F키: 좌우 뒤집기
- **패스**: 막히면 다음 문제로 (10초 페널티)
- **❚❚ 일시정지**: 시간을 멈추고 계속하기 / 그만하기 (그만하면 그 판 기록은 저장되지 않음)

## 기록

- 모드·설정·난이도별 18칸의 최고 기록을 저장합니다. 홈 화면의 '전체 기록 · 공유'에서 한눈에 볼 수 있습니다.
- 제한시간은 푼 문제 수(같으면 패스가 적은 쪽), 스피드런은 걸린 시간이 기준입니다.
- **기기 간 기록 공유**: 기록 창에서 닉네임과 비밀번호를 정하고 다른 기기에서 똑같이 넣으면 휴대폰·PC가 같은 기록을 씁니다. 두 기기의 기록 중 더 좋은 기록이 남습니다. (Firebase)

## 실행

`index.html` 파일 하나로 동작합니다. 아이콘(`favicon.ico`, `icons/`)은 같은 폴더에 둡니다. 빌드가 필요 없고, GSAP·canvas-confetti·글꼴은 인터넷(CDN)에서 불러옵니다.
